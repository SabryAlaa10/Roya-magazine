# Roya Magazine
Static site (HTML/CSS/JS). Deploy: push these files to a GitHub repo, then Settings > Pages > Deploy from branch (main, / root).
- Add an article: add an object to the `A` array in script.js (id, cat, t, sub, by, d, src, url, body).
- Add photos: put files in assets/, then add `img:"assets/x.jpg"` to an article, or `{src:"assets/x.jpg",alt:"..."}` to `PH` for the event section.
- News: re-verify every item and source link before each issue.
